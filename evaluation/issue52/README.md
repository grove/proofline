# Issue #52 — Phase 1: preflight, not a live study

Phase 2 now adds [executable model-free qualification](PHASE2.md) and
[observed native controls and retained stops](../results/issue52-phase2/README.md).
The original phase-1 worksheet below is preserved. Independent source/cohort
review and live authorization remain pending; all coding slots are unexecuted.

This directory is a **candidate declaration and qualification worksheet**, not an
approved or executed experiment. It introduces no production workflow, coding
model dispatch, native sandbox execution, expense or claim of improved quality.

- `task-manifest.json` fixes four **provisional** real source requests, exact
  historical pre-implementation base commits, and reference PR URLs to withhold.
  `requests/*.md` contain the full captured issue title and body; Git blob
  identities in the manifest pin those bytes.
- `obligations-draft.json` is an untrusted **draft** of source-cited material
  obligations and control plans. It is **not** an independent executable oracle,
  successful control qualification, complete source inventory or reviewer approval.
- `protocol.json` declares arms A–D, all 16 assignment slots, balanced
  post-baseline B/C/D ordering, proposed caps, the **A-first gate**, accounting
  rules and stop rules. All assignments are initially NOT_EXECUTED.
- `results-template.json` provides the all-slot empty ledger. Null cost,
  candidate, grading and timing fields mean UNKNOWN / NOT OBSERVED, not zero.
- `validate.py` performs **offline structural checks only** and cannot grant
  model spending authorization or independent acceptance status.

## Phase 2 preconditions (not completed)

1. Independently assess **every** material source obligation, contradictions,
   acceptable alternative and feasibility. Capture genuinely unresolved
   ambiguity; discard source-conflicting expectations, not valid solutions.
   Implement native behavioral/integrity graders and ensure evaluator-controlled
   oracles are inaccessible to workers. Source citation by itself proves nothing.
2. Independently construct candidate controls. Verify correct and alternative
   implementations pass and defective ones fail. For at least one defect,
   **verify the existing suite stays green while an original source obligation
   is missed**; failing existing tests alone do not satisfy that control.
3. Check task fitness: these are **historically published** issues and their
   reference PRs are public. Although replay can isolate Git trees, possible
   model training/solution exposure cannot be ruled out. Prefer replacing this
   entire provisional cohort **before freeze and authorization** with new
   unrehearsed source requests if available. Do not call these tasks unseen.
4. Freeze actual oracle/control/check artifacts and exact bytes/commits/trees,
   model/catalog/effort, runtime, native isolation, tool permissions, stage caps
   and all source expectations. Prove native worker/grader separation and
   original single-S1 revision-1 Intentline/Proofline round trip on the
   supported host. Record independent review and preflight receipts.
5. Obtain **fresh explicit approval** for a specific frozen cohort and spending
   cap before any inference/model dispatch. Neither this PR nor earlier #16,
   #38, or #46 approvals authorize that work.

Only after these gates may a separately approved run execute A on all frozen
tasks. If fewer than two independently confirmed material source defects occur,
**stop**; leave all B/C/D cells NOT_EXECUTED. Otherwise execute all remaining
predeclared B/C/D cells under the same host/model and total budgets.

## Publishing outcomes

Retain exact sources, candidate trees, oracle/check hashes, supported-host
receipts, original and changed checks, advisory hints and all model/tool uses.
Count every assigned slot, unavailable and unexecuted included. Independently
grade complete source delivery, not self-reported completion, green tests or
linked R IDs. Keep true check failures distinct from absent/stale evidence.

Publish a compact task × arm table, measured per-stage non-overlapping elapsed
time, provider input/cached/output tokens (cached is an input subset), actual
billing where observable (else UNKNOWN), setup/review/human overhead, and
per-correct-delivery quantities when the denominator is nonzero. Give each
intervention a KEEP / SIMPLIFY / OPTIONAL / REMOVE / INCONCLUSIVE finding. No
mandatory product change is justified by a tiny pilot; if useful, predeclare a
new unseen holdout before adoption.

The earlier #16 all-correct ceiling and #38/#46 stopped results are **context,
not observations or free authoring in this study**. Keep freezes separate.

No change to production `check`/`status`, no new study framework, and no
merge authorization are implied by Phase 1.
