## Verdicts, costs and conclusion

Use the same assessor and rules for both arms, without worker feedback. Record
supported, violated, disputed and not-demonstrated clauses. PASS requires every
material clause supported; DEFECT requires a genuinely violated original clause.
A completed handoff with such a defect is false acceptance; a correct blocked
handoff is unnecessary blocking. Keep green-original-test omissions separate.
Unavailable attempts never become proven incorrect, and all eight assigned
slots remain in every denominator. Stop on unavailable required grading, native
access/isolation, drift or budget exhaustion. No retries, repairs or task swaps.

Four pairs and one attempt each cannot establish a population reliability or
optimal default. Predeclare INCONCLUSIVE for a ceiling, fewer than two resolved
ordinary-arm defects, unavailable/unexecuted pairs, or unknown full overhead.
KEEP would require a useful paired fidelity gain that pays for **all** checklist
preparation/distribution and execution overhead. SIMPLIFY is appropriate only
if a demonstrated gain survives a specifically identified reducible preparation
cost; REJECT if measured full overhead dominates or fidelity worsens. Do not
use unknown preparation tokens/human work as zero. Actual billing is UNKNOWN;
price sensitivity, if supplied, is a separate calculation using uncached input,
cached input and output prices, never cached-input double counting.
